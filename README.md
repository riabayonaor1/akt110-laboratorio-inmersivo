# AKT 110 laboratorio inmersivo

Presentación del banco didáctico de arranque, encendido y carga de un motor AKT Special 110 X.

Proyecto de Yairan Daniela Ascanio Tellez y Maida Alejandra López Garnica. Técnica en mantenimiento de motos y motocarros, I. E. Carlos Julio Torrado Peñaranda, articulación con el SENA.

## Publicación

Este repositorio contiene una copia idéntica de los archivos estáticos de la versión 3 publicada en Sites, commit de origen `aafade7265ac103ef0a9514b5354ab707e5d83ae`. GitHub Pages publica la raíz de la rama `main`. El archivo `.nojekyll` mantiene los archivos estáticos sin transformación.

No se necesita un proceso de compilación. Para una vista local, servir esta carpeta por HTTP con `python3 -m http.server 4173`.

## Contenido

Motor 3D con acercamientos al arranque, bujía y generador; recorrido continuo por un taller; tres animaciones HyperFrames automáticas con explicaciones sincronizadas; fotos y videos del trabajo real; presupuesto de 480.000 COP con mesa 3D y fajos simbólicos; conclusión.

Las fotografías, videos, nombres, logotipos y contenido académico proceden del material aportado del proyecto. Las geometrías 3D, la separación de piezas y los circuitos son aproximaciones didácticas; no son CAD oficial, plano de cableado ni mediciones del banco.
